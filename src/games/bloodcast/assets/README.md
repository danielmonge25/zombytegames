# BLOODCAST art — drop files here

Images in this folder are picked up automatically, resized and converted to WebP at build time.
Any of `.png .jpg .jpeg .webp .avif` works. No code changes needed.

| File / folder | What it replaces |
| --- | --- |
| `key-art.png` | The illustrated night scene in the BLOODCAST hero and on the home page |
| `cover.png` | The cartridge art on game cards and in the launcher |
| `screenshots/` | The screenshot gallery (see the README inside) |
| `world/` | The four World map slots: `castle`, `graveyard`, `garden`, `waterways` |
| `fish/` | Fish collection art, one file per fish id: `fish-001.png`, `fish-002.png`, … |
| `characters/` | `girl.png` (the mysterious girl) and `player.png` (customization mirror) |

Tip: export at 1920–2560px wide. Bigger is fine; the build shrinks it.
