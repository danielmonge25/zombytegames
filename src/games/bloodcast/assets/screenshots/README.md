# BLOODCAST screenshots

Drop screenshots here and push. They appear in the gallery (grid + fullscreen lightbox) automatically.

- Order = file name order, so number them: `01-...`, `02-...`
- The file name becomes the caption and alt text:
  `03-fishing-at-the-pond.png` → "Fishing at the pond"
- As soon as one real screenshot exists, the "coming soon" placeholder frames disappear.
